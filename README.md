                                                    Data Analytics Capstone Project

*Project Overview
An end-to-end data analytics project covering data cleaning, EDA, visualization, and a Power BI dashboard.

*Problem Statement
Analyze sales performance across regions and product categories to identify growth opportunities.

*Dataset Description
25 sales orders including customer, product, region, sales, profit, and satisfaction data.

*Tools Used
Python (pandas, matplotlib, seaborn), Power BI Desktop, Git & GitHub

*Data Cleaning Process
Removed 1 duplicate row, filled missing values with median, converted OrderDate to datetime.

*EDA
Descriptive statistics, correlation analysis, and outlier detection performed - see eda.py and eda_explanation.txt.

*Visualizations
5 charts: Sales by Category, Monthly Trend, Quantity vs Sales, Sales Boxplot, Correlation Heatmap.

*Power BI Dashboard
Interactive dashboard with 3 KPI cards, 4 visualizations, and 2 slicers - see capstone_dashboard.pbix.
